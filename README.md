# Club Battle

Games for our club battles.

- [claw-machine](claw-machine/) — digital claw machine controlled with hand gestures
- [ai-sketch-guess](ai-sketch-guess/) — Sketch Battle: two players draw the same prompt in 30 seconds and an AI judges which drawing is better

Deploy with `docker compose up -d --build` from this folder. See [ai-sketch-guess/README.md](ai-sketch-guess/README.md#deploying) for details.
